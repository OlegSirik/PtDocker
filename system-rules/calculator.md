# Calculator — системные правила

Проверять при генерации и изменении тарифа / calculator vars.

## Виды переменных калькулятора

Согласовывать с продуктовым словарём и `isTarifFactor`:

- Вход расчёта quote опирается на поля с `isSystem` или `isTarifFactor` (см. OpenAPI quote).
- Не удалять/переименовывать коды, на которые ссылаются формулы, без обновления формул.

## Генерация

- `varCode` формул и COEFFICIENT/COVER должны существовать в доступном контексте.
- Не подставлять в quote-схему поля с пустым смыслом для тарифа.
