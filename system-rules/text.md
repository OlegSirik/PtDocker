# TEXT — системные правила

Проверять при генерации и правке текстовых шаблонов (`varType = TEXT`).

## Источник правды

- Править TEXT **на LOB**.
- **DEV**-продукт при чтении / печати подставляет TEXT с текущего LOB.
- **PROD** — snapshot TEXT, зафиксированный при publish.

## Шаблон

- `varValue` содержит плейсхолдеры `{{varCode}}` (и фильтры `|…` при необходимости).
- Ссылаться только на существующие в контексте коды (IN / MAGIC / CONST / VAR и т.д.).
- Пустой `varPath` у TEXT обычно означает: шаблон для ПФ/digest, не поле wire JSON.

## Генерация

- Не дублировать `varCode` TEXT с кодами схемы IN.
- Не затирать TEXT продукта вручную в обход LOB на DEV.
