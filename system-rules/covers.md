# Covers — системные правила

Проверять при генерации и изменении покрытий (LOB `mpCovers` / product packages covers).

## Состав

- `coverCode` — стабильный код покрытия; не переименовывать без миграции словаря (`co_*` vars) и калькулятора.
- Покрытие связано с пакетами продукта; удаление/добавление должно согласовываться с `COVER`-переменными и тарифом.

## Генерация

- Не создавать дубликаты `coverCode` в рамках LOB/продукта.
- Системные поля покрытия (код, связь со схемой) не ломать произвольно; продуктовые overrides — только в разрешённых полях.
