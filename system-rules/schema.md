# Schema — системные правила

Проверять при генерации атрибутов схемы договора (`INSURANCE_CONTRACT` / `mt_attribute_def`).

## Каскад

- Новые атрибуты схемы попадают в LOB и DEV-продукты каскадом (часто с `isDeleted=true`, пока не включат).
- Между схемой, LOB и продуктом **нет live-ссылки** на каждый save: состав и пути согласуются при add/каскаде и новой DEV-версии.

## Системные атрибуты

- `isSystem` на схеме/продукте защищает идентичность поля — см. [vars.md](vars.md).
- `varPath` должен быть валидным JsonPath к wire JSON, если атрибут в API.

## Генерация

- Не создавать конфликтующие `varCode` / `varPath`.
- `OBJECT` — группировка; листья API — как правило `IN` с путём.
