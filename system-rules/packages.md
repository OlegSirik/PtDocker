# Packages — системные правила

Проверять при генерации пакетов продукта и файлов печатной формы.

## Пакет

- `code` / номер пакета должен согласовываться с `insuredObjects[].packageCode` в API.
- Состав covers в пакете — подмножество доступных покрытий LOB/продукта.

## Файлы ПФ (`files`)

- `fileCode` — тип формы (например POLICY); печать собирает части с одним `fileCode`.
- `fileNr` — порядок склейки PDF.
- `isStatic` — статичный PDF без подстановки vars; иначе заполнение через `VariableContext` / TEXT.
